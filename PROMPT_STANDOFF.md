# ПРОМПТ: максимально реалистичный тактический шутер от первого лица в стиле Standoff 2 — с нуля

Это инструкция для ИИ-кодера / агента, который соберёт игру с нуля. Передай этот
текст агенту вместе с правами создавать файлы и запускать локальный dev-сервер.
Требуй рабочий билд после КАЖДОГО этапа (раздел 13) и прогон проверок из раздела 12.
Никаких «заглушек»: каждая механика должна реально работать в браузере, а не «должна работать».

---

## 0. Как пользоваться этим промптом
- Вводная: «Сделай браузерную игру — тактический 5v5 шутер в стиле Standoff 2, строго по
  спецификации ниже. После каждого этапа выдавай играбельный билд и прогоняй чек-лист приёмки».
- Если агент предлагает упростить механику — запрещай, требуй полной реализации.
- Версия файлов: меняй `?v=N` в `<script>` при каждом билде, чтобы браузер не кэшировал.
- Проверяй в реальном браузере (headless Chromium + WebGL/swiftshader допустимо для автотестов),
  а не только «по коду».

## 1. Концепция
Командный тактический шутер (атака/защита с бомбой), десктоп + мобильный веб. Упор на:
точный контроль оружия, экономику, раундовую структуру, реалистичную баллистику и честный
сетевой код. Визуальный язык — как Standoff 2: чистые материалы, читаемые силуэты, яркие скины.

## 2. Стек технологий
- Движок: Three.js (r16x) + TypeScript + Vite. Рендер собственный, без тяжёлых редакторов.
- Физика: собственная лёгкая — капсульный коллайдер игрока, AABB для мира, лучевые трейсы.
  НЕ используй полноценный физический движок (бокс2d/bullet) — он убьёт предсказуемость спрея.
- Сеть: Node.js + WebSocket (TypeScript), авторитетный сервер, тикрейт 128 (для веб допустим 64).
- Звук: WebAudio с HRTF-панорамой (направление+дальность) + фильтр окклюзии по трассе луча.
- Прогресс: IndexedDB локально + опционально бэкенд для лидербордов/инвентаря.

## 3. Архитектура и тикрейт
- Клиент-сервер. Сервер — источник истины (позиции, пули, раунд, экономика).
- Фиксированный шаг симуляции `dt = 1/TICK`. Клиент рендерит с интерполяцией между
  последними двумя снэпшотами (interp ~100–150 мс).
- Команды ввода шлются с таймстампом; сервер применяет с lag compensation (перематывает
  позиции назад на ping/2 клиента при проверке попадания).
- Мир отделён от рендера: сервер шлёт снэпшоты (позиция, скорость, состояние оружия, HP, флаги),
  клиент предсказывает своё движение и делает reconciliation при расхождении.

## 4. Контроллер игрока (FPS)
- Pointer Lock; чувствительность в рад/px, ЕДИНАЯ для захвата курсора и без него (без
  «позиционного джойстика» у края окна). Настраивается в меню, хранится в localStorage.
- Движение: ускорение/замедление (аналог `sv_accelerate ≈ 10`, `sv_friction ≈ 5.2`),
  макс. скорость ходьбы/бега/приседа. Скольжение вдоль нормали стены при столкновении.
- Воздушный контроль (air-strafe): частичное изменение скорости в воздухе, без чит-банихопа,
  но с лёгким сохранением горизонтального импульса.
- Присед (Crouch): ниже хитбокс, медленнее, точнее. Прыжок (Space): гравитация подобрана под
  высоту прыжка ~50–55 юнитов; Jump velocity вычисляется из гравитации и целевой высоты.
- Выносливость (Stamina): бег ограничен, восстанавливается при ходьбе/стое.
- Коллайдер игрока: капсула (радиус ~16, высота ~72 юнита). Проверка «стоит ли на поверхности»
  — луч вниз + снэп к верхушке AABB при приземлении.
- Нет рывков камеры: первое движение мыши после старта/возврата курсора только фиксируется,
  не применяется (защита от `movementX` «от нуля» в первом событии).

## 5. Оружие и баллистика
Для каждого ствола — таблица параметров (data-driven, не хардкод в логике):
- Урон (базовый) + falloff по дистанции (пороги и множители).
- Пенетрация: толщина пробития по материалам (дерево/металл/бетон), потеря урона при пробитии,
  макс. число преград.
- Точность: spread базовый, при движении, при приседе, в воздухе; first-shot accuracy.
- Отдача: pattern (массив смещений для первых N выстрелов) + recovery (возврат к центру) +
  лёгкий случайный разброс на каждый выстрел. Полуавто/авто/очередь/дробовик/нож.
- Хитбоксы: голова (×4), грудь (×1), живот (×1.1), руки/ноги (×0.7); отдельные боксы на
  торс/голову/конечности, обновляются по позе. Hit регистрируется сервером по трассе луча.
- Визуал: tracer, огонь из дула, дым, звук выстрела с затуханием по дистанции.

## 6. Экономика и раунды
- Валюта `$`: стартовый баланс, награды — kill +, победа раунда +, loss bonus (стрик до 5).
- Бай-меню: пистолеты, основное, тяжёлое, гранаты, броня/кефлар, утилити. Категории + hotkeys.
- Структура: Freeze time (бай-тайм) → GO → plant/defuse. MR12/MR15 (до 12/15 побед) + Overtime.
- Бомба: plant ~3 с, таймер взрыва ~40 с, defuse ~5/10 с (с/без китайца), радиус и урон взрыва,
  звук «bomb tick». Респауна внутри раунда НЕТ (как в CS/Standoff).

## 7. Карты и дизайн уровней
- 3–5 карт: деф-карта с 2 сайтами (A/B), Mid, связки. Навмеш для ботов.
- Читаемые силуэты, контрастные цвета, callouts (A site, Mid, Top, Tunnel и т.д.).
- Освещение: направленный свет + тени, ambient без пересветов. LOD по дистанции.
- Материалы с физикой пробития (см. раздел 5).

## 8. Сетевой код (подробно)
- Client-side prediction для локального игрока.
- Server reconciliation: при снэпшоте сравниваем предсказанную позицию с серверной; если
  расхождение > порога — плавно исправляем.
- Lag compensation: сервер хранит буфер позиций (~1 с) и при shot-команде перематывает мир
  на время отправки команды клиентом (ping/2).
- Interpolation для удалённых игроков (рендерим на 100–150 мс назад, не «в настоящем»).
- Tickrate 128; сжатие снэпшотов (квантизация позиций, дельта-кодирование).

## 9. Звук
- HRTF-панорама для шагов/выстрелов/гранат (направление + дальность).
- Occlusion: приглушение/фильтр НЧ при трассе луча через стену.
- Footsteps: разные для бега/ходьбы/приседа, громче при беге.
- Пространственный звук бомбы, реплики (опц.).

## 10. ИИ ботов (тренинг/одиночка)
- FSM: Patrol → Investigate (услышал/увидел) → Engage → Reload/Retreat → Search.
- Навигация по navmesh (A* / flow field), cover points, peek/hold поведение.
- Реакция: задержка реакции (human-like), точность ниже идеальной, использование укрытий.
- Скорость ботов ВСЕГДА чуть ниже игрока (настраиваемый коэффициент), чтобы не догоняли.

## 11. UI / HUD
- HUD: HP, броня, патроны, гранаты, миникарта (опц.), таймер раунда/бомбы, деньги, килл-фид,
  задачи (plant/defuse).
- Меню: главное, лобби, бай-меню (категории), пауза, настройки (чувствительность, громкость,
  crosshair, клавиши), scoreboard (Tab) с K/D, ADR, MVPs.
- Экран результатов раунда/матча, MVP, награды.
- Скины/кейсы (опц.): инвентарь, крафт, торговля — как монетизация.

## 12. Критерии приёмки (проверки)
- Камера: первый запуск = последующие (нет рывка), поворот плавный, без «ускорений».
- Движение: скорость ходьбы/бега/приседа корректна; нет прохождения сквозь стены; нет телепортов.
- Оружие: спрей воспроизводим; first-shot accuracy; пенетрация работает; хитбокс-множители верны.
- Раунд: freeze time, plant/defuse таймеры, win/loss бонусы, MR.
- Сеть: предсказание без видимых откатов при пинге < 60; lag comp корректна.
- Звук: направление шагов угадывается; окклюзия слышна.
- Производительность: 60 FPS на среднем железе, draw calls в бюджете, нет утечек памяти.

## 13. План этапов (MVP → финал), каждый — отдельный билд
1. Проект + сцена + контроллер (ходьба, прыжок, камера, коллизии). — играбелен локально.
2. Оружие: 1 пистолет + 1 автомат, спрей, хитбоксы, урон. — стрельба по мишеням.
3. Карта-прототип (1 сайт) + навмеш + боты FSM. — боты ходят и стреляют.
4. Раунд / экономика / бомба. — полноценный раунд 1vБоты.
5. Сетевой код (prediction, reconciliation, lag comp) на локальном сервере. — 2 клиента.
6. Звук HRTF + окклюзия.
7. UI/HUD/меню/скорборд/скины.
8. Карты 3–5, баланс, оптимизация, полировка.
